System Architecture & Engineering Design

An inside look at the software architecture, design patterns, computer vision pipelines, and multi-model LLM orchestration powering KissanConnect.

Architectural Pattern

Service-Oriented Decoupled Architecture

Originally conceived as a hackathon proof-of-concept with monolithic view controllers, KissanConnect was completely refactored into an enterprise-tier pattern strictly adhering to Separation of Concerns (SoC) and the Single Responsibility Principle (SRP).

KissanConnect Enterprise Architecture: ├── kissanconnect/urls.py # Root URLconf with dual-namespace resilience ├── main/views.py # Lean HTTP/REST Controller Layer ├── main/services/ │ ├── ai_service.py # Multi-Model Groq LPU + Gemini Orchestration │ ├── disease_service.py # Lazy-Loaded TensorFlow MobileNet CNN │ ├── weather_service.py # OpenWeatherMap Telemetry & Spraying Rules │ ├── crop_service.py # Multi-Variable Soil & Seasonal Heuristics │ ├── carbon_service.py # Sentinel-2 Multispectral Remote Sensing (MRV) │ └── report_service.py # Vector ReportLab PDF & XlsxWriter Engine └── main/models.py # Normalized Relational Data Schema (SQLite/PostgreSQL)
Key Engineering Design Decisions:
  • Zero-Overhead Lazy Model Loading: Heavy TensorFlow dependencies and the 573MB deep learning weights (plant_disease_prediction_model.h5) are dynamically loaded into memory only on the first diagnostic inference request. This eliminates server reboot freezes and ensures instant cold-starts on container platforms.
  • Multi-Tier LLM Resilience: User agronomist queries are dispatched to ultra-fast Groq LPU hardware running openai/gpt-oss-20b for sub-second responses. If rate-limits occur, traffic smoothly fails over to Google Gemini 3.5 Flash with strict token caps (≤ 450 tokens), backed by localized offline heuristic rules.
  • Strict Language Preservation: Natural language pipelines enforce strict language preservation, ensuring English queries never inadvertently receive Hindi or regional responses unless explicitly requested by the farmer.
  • User Isolation & Authentication: Full user authentication with personal dashboards, private plant pathology scan history, and e-commerce procurement histories linked to individual farmer profiles.
